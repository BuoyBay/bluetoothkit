# Bluetooth adapters

Read local Bluetooth adapter snapshots through BlueZ or Windows SetupAPI.

Import `bluetoothkit` or `bluetoothkit.BluetoothKit`. The supported public entry points are listed in the [API contracts](api.md); platform backend modules are implementation details.
